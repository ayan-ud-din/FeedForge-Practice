
# FeedForge


## Tech Stack
- React + Vite
- Node.js + Express
- MongoDB
- Axios
- ImageKit

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ayan-ud-din/FeedForge-Practice.git
```

Install dependencies in both the `Backend` and `Frontend` folders:

```bash
npm install
```

Add your environment variables to `Backend/.env`, then start the backend with:

```bash
node server.js
```

Start the frontend from the `Frontend` folder:

```bash
npm run dev
```
